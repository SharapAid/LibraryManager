# LibraryManager

A lightweight, efficient, and user-friendly desktop application designed for library management, built using **Java Swing** and **SQLite**.

## 🚀 Key Features
* **Interactive Data Tables:** Full CRUD operations for Books, Clients, and Loans.
* **In-Place Cell Editing:** Fast and intuitive inline data modification directly inside the table cells (Excel-style) with instant SQLite database synchronization.
* **Smart Context Menus:** Dynamic `JPopupMenu` on right-click for quick row selection, editing, and deletion.
* **Advanced Navigation & UI:** * Seamless horizontal and vertical cell tracking with a live-updating Status Bar.
  * Input validation with custom placeholder behaviors and phone number masks.
  * Real-time search filter and row counter.
* **Reliable Storage:** Embedded SQLite database integration for standalone local data persistence.

## 📦 How to Run
You can download the ready-to-run executable from the **[Releases](https://github.com/sharapaid/LibraryManager/releases)** section.
1. Make sure you have **Java 21 or higher** installed.
2. Double-click the downloaded `.jar` file to launch the application.
